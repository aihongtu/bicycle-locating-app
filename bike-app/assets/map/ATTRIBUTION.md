# 离线地图演示数据

本目录的 `sjtu-minhang.json` 由 OpenStreetMap 数据裁剪、简化而来。

- 数据来源：OpenStreetMap（https://www.openstreetmap.org/）
- 数据许可：Open Database License (ODbL) 1.0
- 署名：© OpenStreetMap contributors
- 演示范围：上海交通大学闵行校区周边约 2.4 km × 2.4 km
- 生成方式：`bike-app/tools/build-map-data.js`，通过 Overpass API 拉取后简化

该数据仅用于本地演示/离线示意图，不作为导航或测绘依据。
正式在中国大陆发布地图产品时，请使用具备相应资质的地图服务。
