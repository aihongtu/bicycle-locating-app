# 自行车定位助手

一个以手机界面呈现的自行车定位与骑行记录 Web App。它帮助骑行者查看车辆位置、记录真实骑行轨迹、回顾骑行数据，并管理个人资料。项目目前运行在电脑浏览器中；本地版暂未接入真实附近骑友网络，骑友页为空态，不会生成虚拟骑友。

## 项目解决的问题

- 停车后不容易找到自行车：在地图上查看车辆标记、方向和距离，并使用发光、响铃等提示辅助辨认。
- 缺少骑行数据记录：通过浏览器定位记录路线、速度和时长，查看里程、平均速度及估算热量。
- 缺少个人资料和骑友流程演示：在本地管理资料；附近骑友感知与好友/聊天流程等待联网版本。

## 主要功能

- **找车与车辆管理**：查看车辆位置、方向和距离；查看车辆信息；添加或删除车辆；查看模拟步行指引；没有硬件时可触发模拟发光和响铃效果。
- **地图**：优先加载高德地图 JavaScript API；如果网络、Key 或 API 加载不可用，则回退到 Canvas 模拟地图。找车页可请求浏览器定位。模拟地图支持动态范围与“看全路线”、高清屏、拖拽/滚轮/双指缩放、深浅色适配；内置上海交通大学闵行校区 OSM 离线数据，可在 **P09 仪器风** 与 **真实城市风** 之间切换，区域外回退程序化示意地图。
- **ESP32-S3 硬件原型**：找车页可通过 Web Bluetooth 连接 ESP32-S3，发送响铃和发光指令，并接收 ESP32 转发的 Quectel GNSS 位置；响铃通过 I2S、MAX98357A 和扬声器播放提示音，发光由 GPIO 7 控制外接灯驱动模块，固件会在 8 秒后自动关灯。GNSS 通过 UART 接到 ESP32，电脑 USB 串口只用于烧录和调试。完整固件、接线和烧录说明见 [`bike-app/firmware/esp32s3_bike/`](bike-app/firmware/esp32s3_bike/)。
- **骑行记录**：开始、暂停、继续和结束 GPS 轨迹记录；查看路线、分段速度、里程、时长、平均速度和估算热量，并查看历史记录。今日多次骑行会聚合统计；可逐段隐藏/恢复今日路段，汇总和地图只显示剩余路段。配速低于 3 分钟/公里显示为黄色，3–9 分钟/公里为绿色，超过 9 分钟/公里为红色；静止或无速度数据为灰色。
- **骑友**：本地版保留入口与数据结构，但**不生成虚拟骑友**，也不会发现真实用户；附近页显示空态，加好友/聊天等待联网版本。
- **个人资料**：编辑用户名、性别、生日、爱好、简介；选择预设头像或上传图片；上传图片会先压缩到最长边 256px，降低本地存储占用。
- **偏好与备份**：切换浅色/深色主题和中文/英文界面；导出或导入本地 JSON 备份，备份包含资料、车辆、骑行、社交以及主题/语言/隐私同意状态。英文界面采用内置文案翻译，未覆盖的文案可能仍显示中文；地图底图保持高德地图原有语言。

## 安装与启动

项目没有 npm 依赖或构建步骤。需要安装 Node.js，并使用支持 Geolocation 的现代浏览器。使用 Chrome 或 Edge 可获得较好的 Web Bluetooth 支持。

### Windows 启动

在 PowerShell 中从项目根目录运行：

```powershell
cd .\bike-app
node server.js
```

打开浏览器访问 <http://localhost:8080>。按 `Ctrl+C` 停止服务器。也可以双击 `bike-app/start-server.bat` 启动服务器；`bike-app/start-app.bat` 会尝试启动服务器并打开浏览器。

服务器使用 Node.js 内置模块提供静态文件，不需要安装额外包。默认 HTTP 端口为 `8080`；如果本地已有服务占用该端口，可在启动前设置 `PORT` 环境变量。服务器仅用于提供本地网页文件，不提供账号、云同步或骑友联网服务；`certs/`、`*.private.config.json`、`*.pem/*.key/*.bak/*.log` 等私钥/私有配置/备份文件已被静态服务拒绝，不会通过 HTTP 下载。`js/amap-config.local.js` 是页面必须加载的高德配置，仍会作为普通脚本提供；高德 Key 属于客户端可见凭据，请在高德控制台限制允许的来源域名。

### 地图和浏览器权限

高德地图通过 `bike-app/js/amap-config.local.js` 中的本地配置加载，需要有效的高德 JavaScript API Key、安全密钥和网络连接。首次配置时，将 `bike-app/js/amap-config.local.example.js` 复制为 `bike-app/js/amap-config.local.js` 并填写凭据。该本地文件已加入忽略规则，不应提交。没有本地配置或地图脚本加载失败时，应用会使用内置模拟地图。

模拟地图的演示数据位于 `bike-app/assets/map/sjtu-minhang.json`，由 OpenStreetMap 数据裁剪而来（上海交通大学闵行校区周边约 2.4 km × 2.4 km），署名 **© OpenStreetMap contributors**，许可 ODbL；地图上的“风格”按钮可在 **P09 仪器风** 与 **真实城市风** 之间切换。演示区外或数据未加载时，自动回退到程序化示意地图。需要强制查看模拟地图（即使高德可用）时，访问 `http://localhost:8080/?sim=1`。

浏览器定位和蓝牙连接需要安全上下文及用户授权。通过 `http://localhost:8080` 本机访问通常可使用浏览器的安全上下文能力；手机等设备通过局域网访问时，还需要正确配置并信任 HTTPS 证书。拒绝定位权限时，找车页无法取得当前位置，骑行页也无法记录真实 GPS 轨迹。

## 使用方法

1. 启动本地服务器并打开 `http://localhost:8080`。
2. 使用底部导航切换 **找车、骑行、骑友、我的** 四个页面。
3. 在 **找车** 页面查看车辆；可打开车辆管理添加或删除车辆，点击地图上的车辆查看信息。连接 ESP32-S3 原型后可测试响铃和发光；请先按 [`bike-app/firmware/esp32s3_bike/README.md`](bike-app/firmware/esp32s3_bike/README.md) 核对接线、供电和烧录步骤。
4. 使用车载 GNSS 时，先按固件说明将 GNSS 模块 UART 接到 ESP32-S3，再烧录固件；在找车页通过 **寻找并连接设备** 连接 ESP32，地图会收到车载 GNSS 位置。ESP32 的 USB 线仍用于供电、烧录和串口调试，不再承担 GNSS 数据传输。
5. 在 **骑行** 页面点击“开始记录”，允许浏览器使用位置；骑行过程中可暂停或继续，结束后保存记录并查看统计。记录依赖设备的 GPS 定位能力。
6. 在 **骑友** 页面查看空态；本地版不会发现真实用户，也不会生成虚拟骑友，加好友/聊天等待联网版本。
7. 在 **我的** 页面编辑资料、设置头像、切换语言或主题，或导出/导入备份文件。

## 测试

纯逻辑测试（无需服务器）：

```powershell
cd .\bike-app
node test\run.js
```

局域网访问测试需要先运行 `node server.js`，再设置环境变量：

```powershell
$env:TEST_LAN=1; node test\run.js
```

不设置 `TEST_LAN=1` 时，局域网测试会打印 `SKIP` 并跳过。

## 输入与输出示例

应用通过页面操作和浏览器权限获取输入，不使用命令行标准输入。下面的数值仅用于说明数据形状；实际骑行统计取决于设备 GPS 采样和路线。

### 骑行记录

**输入**：点击“开始记录”，允许定位；骑行后点击“结束并保存”。浏览器提供的位置点和时间戳用于生成路线。

**输出**：页面显示路线和统计数据，结构示意如下：

```json
{
  "distanceKm": 5.2,
  "durationMin": 24,
  "avgSpeedKmh": 13,
  "caloriesKcal": 150
}
```

热量是应用的估算值，不是设备实测值。完整骑行记录还包括日期、起止时间、GPS 点和路线分段。

### 备份文件

在 **我的 → 数据备份与恢复 → 导出备份** 下载 JSON 文件。导出结构示意如下：

```json
{
  "version": 1,
  "exportedAt": 1792000000000,
  "data": {
    "bikeapp.profile": {
      "userId": "me",
      "username": "骑行者",
      "gender": "保密",
      "birthday": "2000-01-01",
      "hobbies": "骑行、露营",
      "intro": "热爱周末骑行"
    },
    "bikeapp.bike": {},
    "bikeapp.rides": {},
    "bikeapp.social": {},
    "bikeapp.theme": "light",
    "bikeapp.language": "zh",
    "bikeapp.privacyConsent": "1"
  },
  "avatars": {}
}
```

示例中的空对象仅表示省略了具体车辆、骑行、社交和头像数据。实际备份会导出浏览器当前保存的数据、设置类状态以及已上传的头像；通过“导入恢复”选择备份 JSON 后，应用会恢复数据并重新加载。

## 数据与隐私说明

个人资料、车辆、骑行、好友和聊天数据保存在当前浏览器的本地存储中；上传头像会压缩后存入本地资料，并同步写入 IndexedDB。本项目没有自建后端或云同步。使用高德地图时，地图 SDK 和地图请求会访问高德服务；定位由浏览器在用户授权后提供。清理浏览器站点数据会删除本地资料，请先导出备份。

## 安全提示

高德凭据应只放在被忽略的 `bike-app/js/amap-config.local.js`；HTTPS 私钥使用被忽略的 `bike-app/certs/key.local.pem`，证书文件为 `bike-app/certs/cert.pem`。本地服务器已拒绝通过 HTTP 提供 `certs/`、`*.private.config.json`、`*.pem/*.key/*.bak/*.log` 等私钥/私有配置/备份文件，但不要依赖它作为唯一防线。高德 Key 是浏览器端必须加载的客户端凭据，无法通过静态服务器真正隐藏，应限制允许访问的来源域名并定期轮换。`.ppt-work/` 和 `ppt-output/` 也已加入忽略规则，避免提交含个人信息的演示文稿及处理中间文件。若凭据曾经推送到远程仓库，应在服务控制台撤销或轮换，并清理 Git 历史；仅删除当前文件不能移除历史版本中的凭据。

## 已知限制

- **骑友模块**：本地版不生成虚拟骑友，也不会发现真实用户；附近页为空态，加好友/聊天等待联网版本。
- **今日路段隐藏**：只影响今日视图，不修改历史原始数据；隐藏状态保存在本地，跨天后旧 session 的隐藏记录会被清理。
- **闭环补时**：起点与终点接近时，只补“缺口距离”，时长按缺口/最后一段均速估算；这是近似值，不是实测回程时间。
- **静止配速**：速度为 0 或无速度数据时显示灰色，不参与“快/正常/慢”的黄色/绿色/红色判断。
- **英文界面**：内置文案翻译未覆盖全部动态文案，部分内容仍可能显示中文。
- **离线地图数据**：目前只覆盖上海交通大学闵行校区周边约 2.4 km × 2.4 km；区域外自动回退程序化示意地图。数据来自 OpenStreetMap（ODbL），仅用于本地演示，不作为导航/测绘依据；正式发布请使用合规地图服务。
- **附近骑友**：需要后端/联网能力，当前本地静态服务器不提供该能力。
