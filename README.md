# 自行车定位助手

一个以手机界面呈现的自行车定位与骑行记录 Web App。它帮助骑行者查看车辆位置、记录真实骑行轨迹、回顾骑行数据，并管理个人资料和模拟骑友。项目目前运行在电脑浏览器中；附近骑友、好友处理和聊天回复为本地模拟，不连接真实用户网络。

## 项目解决的问题

- 停车后不容易找到自行车：在地图上查看车辆标记、方向和距离，并使用发光、响铃等提示辅助辨认。
- 缺少骑行数据记录：通过浏览器定位记录路线、速度和时长，查看里程、平均速度及估算热量。
- 缺少个人资料和骑友流程演示：在本地管理资料、模拟附近骑友、好友请求和聊天。

## 主要功能

- **找车与车辆管理**：查看车辆位置、方向和距离；查看车辆信息；添加或删除车辆；查看模拟步行指引；触发模拟发光和响铃效果。
- **地图**：优先加载高德地图 JavaScript API；如果网络、Key 或 API 加载不可用，则回退到 Canvas 模拟地图。找车页可请求浏览器定位。
- **蓝牙设备**：支持使用浏览器 Web Bluetooth 选择附近设备并尝试连接。当前项目没有具体自行车设备的 GATT 指令协议，因此真实设备的发光和响铃控制尚未实现；没有可用设备或控制指令时，界面会提供模拟反馈。
- **骑行记录**：开始、暂停、继续和结束 GPS 轨迹记录；查看路线、分段速度、里程、时长、平均速度和估算热量，并查看历史记录。配速低于 3 分钟/公里显示为黄色，3–9 分钟/公里为绿色，超过 9 分钟/公里为红色。
- **骑友**：查看本地生成的模拟附近用户，发送或处理好友请求，管理最多 100 位好友，并进行带模拟自动回复的聊天。
- **个人资料**：编辑用户名、性别、生日、爱好、简介；选择预设头像或上传图片；资料会用于应用内的个人展示。
- **偏好与备份**：切换浅色/深色主题和中文/英文界面；导出或导入本地 JSON 备份。英文界面采用内置文案翻译，未覆盖的文案可能仍显示中文；地图底图保持高德地图原有语言。

## 安装与启动

项目没有 npm 依赖或构建步骤。需要安装 Node.js，并使用支持 Geolocation 的现代浏览器。使用 Chrome 或 Edge 可获得较好的 Web Bluetooth 支持。

### Windows 启动

在 PowerShell 中从项目根目录运行：

```powershell
cd .\bike-app
node server.js
```

打开浏览器访问 <http://localhost:8080>。按 `Ctrl+C` 停止服务器。也可以双击 `bike-app/start-server.bat` 启动服务器；`bike-app/start-app.bat` 会尝试启动服务器并打开浏览器。

服务器使用 Node.js 内置模块提供静态文件，不需要安装额外包。默认 HTTP 端口为 `8080`；如果本地已有服务占用该端口，可在启动前设置 `PORT` 环境变量。服务器仅用于提供本地网页文件，不提供账号、云同步或骑友联网服务。

### 地图和浏览器权限

高德地图通过 `bike-app/js/amap-config.local.js` 中的本地配置加载，需要有效的高德 JavaScript API Key、安全密钥和网络连接。首次配置时，将 `bike-app/js/amap-config.local.example.js` 复制为 `bike-app/js/amap-config.local.js` 并填写凭据。该本地文件已加入忽略规则，不应提交。没有本地配置或地图脚本加载失败时，应用会使用内置模拟地图。

浏览器定位和蓝牙连接需要安全上下文及用户授权。通过 `http://localhost:8080` 本机访问通常可使用浏览器的安全上下文能力；手机等设备通过局域网访问时，还需要正确配置并信任 HTTPS 证书。拒绝定位权限时，找车页无法取得当前位置，骑行页也无法记录真实 GPS 轨迹。

## 使用方法

1. 启动本地服务器并打开 `http://localhost:8080`。
2. 使用底部导航切换 **找车、骑行、骑友、我的** 四个页面。
3. 在 **找车** 页面查看车辆；可打开车辆管理添加或删除车辆，点击地图上的车辆查看信息，或尝试连接附近蓝牙设备。发光、响铃在当前没有匹配硬件协议时为模拟效果。
4. 在 **骑行** 页面点击“开始记录”，允许浏览器使用位置；骑行过程中可暂停或继续，结束后保存记录并查看统计。记录依赖设备的 GPS 定位能力。
5. 在 **骑友** 页面体验模拟的好友请求和聊天。该页面不会发现真实用户，也不会将消息发送到网络。
6. 在 **我的** 页面编辑资料、设置头像、切换语言或主题，或导出/导入备份文件。

## 输入与输出示例

应用通过页面操作和浏览器权限获取输入，不使用命令行标准输入。下面的数值仅用于说明数据形状；实际骑行统计取决于设备 GPS 采样和路线。

### 骑行记录

**输入**：点击“开始记录”，允许定位；骑行后点击“结束并保存”。浏览器提供的位置点和时间戳用于生成路线。

**输出**：页面显示路线和统计数据，结构示意如下：

```json
{
  "distanceKm": 5.2,
  "durationMin": 24,
  "avgSpeedKmh": 13,
  "caloriesKcal": 150
}
```

热量是应用的估算值，不是设备实测值。完整骑行记录还包括日期、起止时间、GPS 点和路线分段。

### 备份文件

在 **我的 → 数据备份与恢复 → 导出备份** 下载 JSON 文件。导出结构示意如下：

```json
{
  "version": 1,
  "exportedAt": 1792000000000,
  "data": {
    "bikeapp.profile": {
      "userId": "me",
      "username": "骑行者",
      "gender": "保密",
      "birthday": "2000-01-01",
      "hobbies": "骑行、露营",
      "intro": "热爱周末骑行"
    },
    "bikeapp.bike": {},
    "bikeapp.rides": {},
    "bikeapp.social": {}
  },
  "avatars": {}
}
```

示例中的空对象仅表示省略了具体车辆、骑行、社交和头像数据。实际备份会导出浏览器当前保存的数据以及已上传的头像；通过“导入恢复”选择备份 JSON 后，应用会恢复数据并重新加载。

## 数据与隐私说明

个人资料、车辆、骑行、好友和聊天数据保存在当前浏览器的本地存储中，头像保存在 IndexedDB；本项目没有自建后端或云同步。使用高德地图时，地图 SDK 和地图请求会访问高德服务；定位由浏览器在用户授权后提供。清理浏览器站点数据会删除本地资料，请先导出备份。

## 安全提示

高德凭据应只放在被忽略的 `bike-app/js/amap-config.local.js`；HTTPS 私钥使用被忽略的 `bike-app/certs/key.local.pem`，证书文件为 `bike-app/certs/cert.pem`。`.ppt-work/` 和 `ppt-output/` 也已加入忽略规则，避免提交含个人信息的演示文稿及处理中间文件。若凭据曾经推送到远程仓库，应在服务控制台撤销或轮换，并清理 Git 历史；仅删除当前文件不能移除历史版本中的凭据。高德 Key 还应限制允许访问的来源域名。
